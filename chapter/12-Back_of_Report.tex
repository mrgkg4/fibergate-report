\underline{\textbf{R\'esum\'e~:}}\\
Ce projet de fin d'\'etudes propose une solution d'automatisation compl\`ete des
flux de traitement des demandes de raccordement en fibre optique au sein de l'unit\'e
\textit{Guichet OI~: PAR France} d'Orange DTOF\,/\,DINFRA. La solution s'articule
autour de trois piliers comp\'ementaires~: la flotte \textbf{SENTINEL}, un ensemble
de trois agents RPA (Python~+~exchangelib~+~Power Automate) automatisant la validation
des emails POI, le traitement des retours CAFF et la distribution des t\^aches~;
le \textbf{service ML GuichetOI}, un pipeline LayoutLMv3 multimodal entra\^in\'e
sur 872 documents annot\'es atteignant 87,7~\% de pr\'ecision en classification de
documents administratifs~; et la \textbf{plateforme web unifi\'ee}, une application
Angular~17\,+\,Spring~Boot~3 avec RBAC hi\'erarchique, authentification JWT, pipeline
CI\,/\,CD GitHub et h\'ebergement Azure Mantu. L'impact mesur\'e est une r\'eduction
d'environ 95~\% du temps de traitement des flux automatis\'es, soit 12~320~heures
r\'ecup\'er\'ees par an et un gain financi\'er annuel estim\'e
\`a 554~400\,\texteuro{} pour l'unit\'e Guichet OI.

\underline{\textbf{Abstract~:}}\\
This Final Year Project proposes a comprehensive automation of fiber optic connection
request processing workflows at Orange DTOF\,/\,DINFRA's \textit{Guichet OI: PAR
France} unit, operated through Amaris Consulting. The solution comprises three
complementary pillars: the \textbf{SENTINEL fleet}, a set of three RPA agents
(Python\,+\,exchangelib\,+\,Power Automate) automating POI email validation, CAFF
return handling, and Excel-based task distribution; the \textbf{GuichetOI ML
service}, a multimodal LayoutLMv3 pipeline trained on 872 annotated documents
achieving 87.7\,\% document classification accuracy; and the \textbf{unified web
platform}, an Angular~17\,+\,Spring Boot~3 application with hierarchical RBAC, JWT
authentication, GitHub Actions CI\,/\,CD, and an Azure Mantu hosting plan. The measured
business impact is an approximately 95\,\% reduction in processing time across the
automated workflows, 12,320 hours recovered annually, and an estimated financial
return of 554,400\,\texteuro{} per year for the Guichet OI unit.
